# Contributing

Haptics Studio Examples is run by volunteers, so answers and reviews come when someone has time.

## Suggesting a Change

Fork the repository, work on a branch made from `main`, and open a pull request against `main`.

## What Can Be Added

Everything here except the Code of Conduct, which keeps its own attribution, is released under CC BY 4.0. So only add what you made yourself or what its owner allows to be released that way. Audio, images and text taken from a product or a game usually do not qualify, even when they are easy to download.

Each folder that holds sample files has a **Sources** table in its README. Add a row for every file you add, with its source, author and licence.

## Reporting a Problem

Open an issue that says what you did, what you expected and what happened, and which version of the tools you used on which operating system.

A security problem does not belong in an issue. See [SECURITY.md](SECURITY.md).
