# Status

This repository is being built. Its pages are placeholders for a maintainer to fill, and it holds no sample projects yet. It is private and meant to go public.

The documentation restructure is tracked in [basslet/haptics-studio#5](https://github.com/basslet/haptics-studio/issues/5). Its pull requests target the `integration/docs-refactor` branch, which merges into `main` in one pull request, as in Haptics Studio. The Docs workflow runs only on pull requests into `main` and pushes to `main`, so the pull requests into the integration branch get no CI run.

## Before the Repository Opens

- A maintainer reviews all content.
- Placeholders are filled or removed.
