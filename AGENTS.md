# Agent Instructions

Project knowledge lives in `docs/journal/`. Read `STATUS.md` first.

| File | Holds |
| :--: | :---: |
| `STATUS.md` | Where the project stands now |
| `debt.md` | Known problems that are not issues yet |
| `expectations.md` | What is not yet proven, and what would prove it wrong |
| `decisions.md` | Decisions in force, and why |

- The journal describes the current state, not history. Clear out old items; git keeps the history.
- Add anything you find to `debt.md`. A row becomes an issue only when a maintainer approves it; then delete the row.
- You may propose turning a debt row into an issue when the impact is high and the circumstances are clear.
- Everything here and in the issues is public. Keep anything sensitive off GitHub.
