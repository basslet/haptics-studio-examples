# Security

## Reporting a Vulnerability

Do not report a vulnerability in a public issue. Open this repository's **Security** tab and choose **Report a vulnerability**, which keeps the report private. If that button is not shown, open an issue asking [@basslet](https://github.com/basslet) for a private contact, without giving any details of the problem.

This repository holds examples, and the applications that run them live elsewhere. For a problem in the app or the SDK, use the same steps in [Haptics Studio](https://github.com/basslet/haptics-studio) or [Haptics SDK](https://github.com/basslet/haptics-sdk).

Haptics Studio Examples is maintained by volunteers in their free time, so handling is best effort, with no promised response time.
